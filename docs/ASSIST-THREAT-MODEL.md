# Windows Assist threat model

Status: internal design and implementation assessment, **not an independent security audit**. Scope: v1 description bridge, inactive capture components, isolated helpers and the non-injecting guardian. Production input, clipboard/files and network transport are absent. Physical/E2EE/release acceptance remains blocked. Fully compromised local hosts with sufficient privileges are outside the claimed protection boundary.

| Threat / boundary and precondition | Required authority | Enforcement now / proposed endpoint boundary | Negative evidence | Remaining risk |
| --- | --- | --- | --- | --- |
| Malicious remote guest requests input | Scoped device/session proof and native host consent | No native operation route; admission helper requires verifier and local consent | Binding, absent consent, replay tests | No deployed verifier/endpoint to qualify |
| Compromised host renderer forges approval | Independent endpoint proof plus trusted local approval | v1 exposes descriptions only; no generic IPC | Main sender/frame/shape tests, real preload scope checks | XSS still has hosted app/account surface; future endpoint decision open |
| Compromised guest renderer widens scope | Exact guest device/capability/direction | No executor/clipboard/file IPC; proposed endpoint checks each operation | Wrong-device binding and capability tests | Guest device compromise is not solved by UI labels |
| Forged approval or stolen session token | Independent proof, endpoint identity and native consent | Tokens/identity never cross v1; verifier seam rejects unverified fixture | Forged grant tests | Actual issuer/device possession implementation pending |
| Grant replay / old connection | Nonce, generation, strict sequences, original session deadline and current expiry | Offline lease rejects reuse/deadline extension and checks liveness at consent and admission | Duplicate, wrong generation/nonce, deadline, invalid clock and expiry tests | Future network sequencing/reconnect proof Not Verified |
| Revoked permission retains stalled work | Current independently granted capability and local consent | Scoped cancellation invalidates permissions before signalling; failed destinations interrupt stalled reads | Scoped revoke, stalled read/write, cleanup failure and reentrant-stop tests | In-process fixtures do not establish native stop, network revocation or OS resource cleanup |
| Malicious IPC sender / subframe | Exact hosted WebContents, current main frame, fixed origin | V1 handler rejects wrong frame/origin/navigation, limits request rate | VM and actual Electron subframe/bridge tests | IPC serialization resource pressure remains a local process concern |
| Unauthorized local process | Authenticated per-user channel and instance binding | No native listener exists; proposed ACL/challenge boundary | Listener absent by implementation | Native channel attack tests cannot run before implementation |
| Cross-user Windows session | Current authorized interactive SID/desktop | No input path; future native lifecycle/session checks required | Not Verified natively | No cross-user/secure-desktop protection certification |
| Capture without picker / legacy bypass | Explicit chosen source through distinguishable modern request | Production capture disabled; empty media requests remain denied | Real Electron modern and legacy attempts denied; component picker tests | Native capture blocked by Electron ambiguity, #3 |
| Source title/preview injection | Trusted local picker only | TextContent, fixed CSP, local sender/frame validation, no metadata bridge | Malicious-looking title remains text in picker fixture | Previews are sensitive local content; physical privacy test pending |
| Malicious file payload | Independent receive grant and accepted opaque transfer | No OS filesystem broker; bounded stream helper never executes content | Tamper/truncation/size/cancel tests | Malware/scanning/MOTW behavior not implemented |
| Traversal / arbitrary destination / reparse race | Local sender handles and recipient-selected scoped save | Basename validation only; no path accepted or file created by helper | Reserved/traversal/ADS names rejected | Native reparse/TOCTOU/atomic commit requires review; not solved by string validation |
| Unauthorized clipboard reading | Separate current directional consent | No OS clipboard access/monitor; helper inactive by default | Disabled/revoked window and format/size tests | Actual format decoding, gestures and peer identity pending |
| Clipboard spoofing / loops | Authenticated peer payload and current direction | In-memory same-payload dedup; no history or OS sync | Duplicate suppressed; malformed UTF-8 rejected | Dedup is not sender authentication or perfect secret detection |
| Input flood / resource exhaustion | Bound capability and rate/quota | Lease terminates at rate limit; bounded geometry/keys/payloads/chunks | Flood, held-key limit, oversize and stalled-cancel tests | Native transport/concurrency quotas and real load not qualified |
| Stale endpoint / held keys after crash | Parent/lease lifetime and native watchdog | No executor; ledger emits release-all plan; lease expiry timer and terminal revoke | Release plan and revoke/clock rollback tests | OS release after native crash is Not Verified |
| Compromised backend | Independent device/endpoint proof and local consent | No current native authority from backend; proposed issuer trust unresolved | No operation through v1; synthetic verifier refuses bad proof | Do not claim resistance to a compromised authority until independently reviewed design exists |
| Compromised SFU / relay | Authenticated end-to-end media/data confidentiality | Existing web media E2EE retained; no data transport activated | No new media/data route; actual E2EE Not Verified here | Media encryption does not prove clipboard/file/control confidentiality |
| Malicious update artifact | Existing pinned Ed25519 chain and verified installer hashes | Existing verifier/manager, fuses and app identity unchanged | Existing signature/key rotation/hash/installer tests retained | Signing-key or sufficiently privileged host compromise remains material |
| Native module tampering | Reviewed binary provenance, authenticated IPC and package integrity | Locked inactive guardian binary; ASAR-protected hash manifest checked before diagnostic launch; no runtime download | Package hash/source/notice tests; endpoint still unavailable to the web | Future native signing/integrity and removal tests pending |

Permission visibility, a bridge version or source hash is not authorization. Encryption alone is not identity or consent. File SHA-256 detects corruption but supplies neither confidentiality nor peer authentication. No product-level acceptance follows from a table row marked as a unit/helper test.

Guardian-specific limits: issuance diagnostics cannot authorize operations; process heartbeats are not authoritative liveness. DPAPI protects stored seeds for the current user, not a compromised same-user account. File-handle reparse refusal does not eliminate ancestor-directory races. Notifications do not prove an unlocked Default desktop at startup. No input injector exists, so stuck-key recovery is still a future native test requirement. Independent component review approved only the inactive foundation, not the full threat model or product.

HELP & RECOVERY

Troubleshooting

Cannot check for updates?

Check your connection and retry. The official release must include signed metadata. If no release is published, ask your administrator for a signed offline package.

Installation interrupted or files missing?

Close Palisade, refresh detection and select the correct installation folder. Check for a verified release, then choose Repair. A newer release will update the application. Your profile is retained.

Windows blocked the installer?

Follow your organization’s software policy. This utility does not bypass SmartScreen, antivirus, or Windows permissions. Ask your administrator if approval is required.

Remove Palisade

Open Windows Settings → Apps → Installed apps → Palisade → Uninstall. This delegates removal to Palisade’s supported uninstaller. Removing application files is separate from deleting your profile; this utility never deletes your profile.

Reports include versions, Windows version and operation history. Account details, installation paths, credentials and session data are excluded.

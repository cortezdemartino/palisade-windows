# Palisade brand assets

These are the original Palisade identity graphics provided by Onyx Operations Group.

- `palisade-shield.png`: primary shield mark, suitable for application icons and compact layouts.
- `palisade-wordmark.png`: horizontal shield and PALISADE wordmark for headers, installers and site presentation.

The source images have transparent backgrounds. Keep their colors, proportions and artwork intact. Export other sizes or file formats from these originals.

# Palisade for Windows

Windows desktop client for the [Palisade](https://palisade.onyxops.org/) communications platform.

The application uses Electron for Windows integration and loads the existing Palisade web client. Messaging and encryption remain in the Palisade Matrix implementation.

The desktop source, Windows build workflow and signed GitHub Releases updater are being prepared as a standalone project. Official installers will be published under [Releases](https://github.com/cortezdemartino/palisade-windows/releases).

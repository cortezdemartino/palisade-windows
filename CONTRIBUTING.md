# Contributing

Please open an issue to discuss a substantial change before starting work. Keep changes focused, include regression tests for security-sensitive behavior, and update the relevant guide when workflows change.

Run `npm run check` before submitting a pull request. Installer changes must also be tested on Windows. Do not commit credentials, update private keys, Matrix session material or real user data.

Security vulnerabilities should be reported privately to the repository maintainers instead of posted in public issues.
